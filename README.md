# 🧠 Parkinson Disease Detection using Machine Learning

A Machine Learning project to predict Parkinson's Disease using voice measurement features. This project compares multiple classification algorithms and identifies the best-performing model for disease prediction.

---

## 📌 Project Overview

Parkinson's Disease is a progressive neurodegenerative disorder that affects movement and speech. Early detection can improve patient management and treatment. This project uses voice-based biomedical features to classify individuals as healthy or having Parkinson's Disease.

---

## 🎯 Objective

- Detect Parkinson's Disease using Machine Learning.
- Compare different classification algorithms.
- Evaluate model performance using standard metrics.

---

## 📂 Dataset

- **Source:** UCI Machine Learning Repository
- **Samples:** 195
- **Features:** 22 Voice Features
- **Target Variable:** `status`
  - 0 = Healthy
  - 1 = Parkinson's Disease
